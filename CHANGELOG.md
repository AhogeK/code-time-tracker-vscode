# Changelog

All notable changes to the Code Time Tracker VS Code extension are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Repository scaffolding: TypeScript strict mode, esbuild bundling, ESLint flat config, and a
  Mocha + `@vscode/test-cli` test harness
- Extension activation with the `code-time-tracker-vscode.helloWorld` command

## [0.0.1] - 2026-09-14

### Added

- Initial repository created from the VS Code extension template
- `package.json` manifest, `tsconfig.json`, `esbuild.js`, `eslint.config.mjs`, and `.vscode/`
  launch and task configurations
- MIT license, contributing guide, code of conduct, and security policy
